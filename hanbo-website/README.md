# 广东广东广东汉柏能源集团官网 —— 项目说明与编辑指南（给非技术人员）

> **这是什么？**
> 一个正规的「前端 + 后端」网站项目，刚刚搭好框架，里面的公司介绍、项目、联系方式都是**占位内容**（网页里带虚线底纹的文字都是），需要你们替换成真实信息。

## 一、项目结构（前端 + 后端）

```
hanvo-website/
├── index.html          ← 网站页面（前端·结构，首页全屏 + 其余版块自适应滚动）
├── 预览版-双击即看.html  ← ⭐ 预览专用：样式/图片全在这一个文件里，双击即可看完整效果
├── admin.html          ← 留言管理页（后端配套：查看客户留言）
├── css/
│   └── style.css       ← 网站样式（前端·外观，改颜色在这里）
├── js/
│   └── main.js         ← 交互逻辑（前端·中英切换/导航/提交表单）
├── assets/
│   ├── images/         ← 网站正在用的图片（7 张）
│   └── src/            ← 原始大图存档（以后要原图在这里找）
├── server.js           ← 后端程序（处理留言、提供接口）
├── package.json        ← 项目说明文件（不用动）
├── data/
│   └── messages.json   ← 客户留言自动存这里（跑起来后自动生成）
└── README.md           ← 就是本文件
```

**一句话理解：**
- **前端** = 访客浏览器里看到的一切（`index.html` + `css/` + `js/` + `images/`）
- **后端** = 服务器上跑的程序（`server.js`），负责把客户填的留言存下来

## 二、怎么把网站跑起来（本地看效果）

需要先装 **Node.js**（免费，官网 https://nodejs.org 下载 LTS 版，一路"下一步"装好）。

然后打开"命令提示符/终端"，进入本项目文件夹，输入：

```
node server.js
```

看到如下字样就成功了：

```
广东汉柏能源集团官网 - 服务已启动
网站首页 : http://localhost:8000
```

浏览器打开 **http://localhost:8000** 就能看到网站；
**http://localhost:8000/admin.html** 是留言管理页。
想停止服务，在命令行按 `Ctrl + C`。

> **只想快速看一眼效果？** 双击文件夹里的 **`预览版-双击即看.html`**，所有样式、图片都已打进这一个文件里，双击就能看，不用装任何东西（只是留言功能需要后端，预览版里点了会提示）。
> 
> ⚠️ 直接双击 `index.html` 会看到**没有样式的"裸页面"**，这是正常的：正式项目里样式和图片都在外部文件里，必须通过 `node server.js` 启动后访问 `http://localhost:8000` 才能完整显示。

## 三、以后怎么部署上线（二选一）

| 方案 | 适用情况 | 说明 |
|---|---|---|
| **A. 云服务器 + Node**（推荐） | 需要留言功能正常运转 | 买一台云服务器（阿里云/腾讯云，轻量版一年几百元），装 Node.js，把整个文件夹传上去，`node server.js` 常驻运行（用 pm2 守护） |
| **B. 纯静态托管** | 暂不需要数据库 | 把 `index.html` + `css/` + `js/` + `assets/` 上传到任意静态托管（OSS+CDN、Vercel、Netlify）。**注意**：此时留言表单会提示"未启动后端"，需临时关闭表单或换用第三方表单服务 |

**上线前必做清单：**
1. 买域名 + ICP 备案（备案号位置已在页脚预留，非大陆服务器可跳过备案）
2. 给 `/api/messages` 加登录认证（现在是演示页，任何人都能看留言！）
3. 建议把留言对接公司邮箱 / 企业微信 / CRM
4. 开启 HTTPS（云服务器一键申请免费证书）

## 四、日常内容维护（不用写代码）

**改文字：** 用记事本 / VS Code 打开 `index.html`，`Ctrl+F` 搜旧文字，改成新的，保存刷新。
所有带**虚线底纹**的文字都是占位内容。英文翻译改在 `data-en="..."` 引号里。

**改图片：** 把你们实拍图（建议 1200px 宽以上 JPG）覆盖到 `assets/images/` 对应文件名即可，
对应关系见 `assets/src/` 或对照 `index.html` 里的文件名。

**改颜色：** 打开 `css/style.css`，最上面几行就是品牌色：
```css
--navy:  #0A2F4E;   /* 深蓝 */
--blue:  #0E6BA8;   /* 主色 */
--green: #00923F;   /* 品牌绿（Logo 同款） */
```
换成你们的品牌色号，全站自动生效。

**Logo：** 网站现已使用**正式 Logo**（绿色方块网格 + 蓝点，即你们提供的那张图），
文件在 `替换用资源/`：`logo.png`（透明底·网页用）、`logo-白底.png`（白底·办公用）、`logo.svg`（矢量·印刷用）。
如需再换，把新图发我即可。

## 六、常见问题

- **Q：留言存哪了？** → `data/messages.json`，或用 `admin.html` 查看。换数据库时让技术人员改 `server.js` 的 `loadMessages/saveMessages` 两处即可。
- **Q：想加新业务板块 / 新项目？** → 复制 `index.html` 里一个 `<article class="biz-card">` 或 `<article class="proj-card">` 卡片，改内容即可。
- **Q：想要新闻发布后台？** → 下一步可以加（后端已就位，做个简单的"新闻管理"页面即可），或改用 WordPress 之类的 CMS。
- **Q：这些代码安全吗？** → 框架是标准写法，但**留言接口无鉴权、数据存 JSON 文件**都是演示级别，正式上线务必按第三节清单加固，建议找一位懂技术的同事或服务商把关。
